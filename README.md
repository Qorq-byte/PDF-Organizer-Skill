# 📚 PDF Organizer Skill

> 一个面向 AI Agent 的智能 PDF 整理、分类、摘要与知识索引 Skill。

把散落在电脑里的 PDF，从：

> “我不知道这个文件是什么，也懒得一个个打开”

变成：

> **“知道它是什么、讲了什么、重点在哪里、应该放到哪里。”**

---

## ✨ 项目简介

`PDF Organizer` 是一个通用型 AI Agent Skill，专门用于处理和整理大量 PDF 文档。

它不只是简单的 PDF 总结器，而是尝试完成完整的：

```text
PDF
 ↓
文档识别
 ↓
内容提取
 ↓
智能分类
 ↓
关键词提取
 ↓
摘要生成
 ↓
重点信息提取
 ↓
目录/章节识别
 ↓
重复与版本检测
 ↓
文件归档建议
 ↓
知识索引
```

适合处理：

* 学习资料
* 课程讲义
* 教材
* 学术论文
* 科研资料
* 项目文档
* 工作报告
* 会议材料
* 产品说明书
* 通知公告
* 合同和协议
* 电子书
* 资料汇编
* 扫描 PDF

---

# 🚀 核心功能

## 1. 🔍 自动识别 PDF 类型

Agent 会根据文件名、标题、目录、正文结构和语义内容判断 PDF 类型。

例如：

```text
论文
教材
课程讲义
实验报告
项目报告
会议资料
技术文档
产品说明书
合同
通知
电子书
其他
```

同时给出分类置信度：

```text
类型：学术论文
置信度：93%

原因：
文档包含摘要、关键词、方法、实验结果和参考文献。
```

当信息不足时不会强行判断：

```text
document_type: unknown
confidence: low
```
